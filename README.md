# AI Systems Lab

**Independent engineering studies in LLM systems, AI agents, and AI reliability.**

AI Systems Lab is a collection of hands-on engineering case studies focused on understanding, debugging, testing, and improving open-source AI systems.

Each study explores a real technical problem, documents its root cause, implements an independent solution, and validates the result through reproducible tests.

## Engineering Focus

- LLM inference and tool calling
- Agent orchestration and state management
- Retrieval-Augmented Generation (RAG)
- AI system reliability and regression testing
- Python debugging and open-source development

## Methodology

Each case study follows a structured engineering workflow:

1. Investigate and reproduce the reported behavior.
2. Identify the underlying cause.
3. Develop an independent implementation.
4. Write regression tests.
5. Validate the fix with automated tests and static checks.
6. Document the results and limitations.

## About

This repository documents independent engineering exercises using public open-source codebases.

Implementations are maintained in separate forks and are not represented as upstream contributions unless explicitly merged into the original projects.
